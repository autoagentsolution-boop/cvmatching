## E. Disambiguation Rules

### Customer Success vs. Customer Service
- **Customer Success Manager** (renewal, account expansion, churn prevention) → SALES
- **Customer Support Officer** (issue resolution, post-sale service) → OPS
- Rule: If title/desc mentions "retention", "renewal", "upsell", "account growth" → SALES. If "complaint", "support", "issue", "ticket" → OPS.

### Operations Manager (Generic)
- **Operations Manager - Manufacturing** → OPS
- **Operations Manager - Tech/Infrastructure** → TECH
- **Operations Manager - Sales** → SALES
- Rule: Check context (team, metrics). Manufacturing/logistics context → OPS. Tech/DevOps context → TECH. Sales/revenue context → SALES.

### Project Manager - IT vs. Generic
- **Project Manager - IT/Software** → TECH
- **Project Manager - Construction** → OTHER (Engineering)
- **Project Manager - General** → OPS
- Rule: If CV mentions software dev, coding, sprint, agile tech context → TECH. If construction/engineering → OTHER. Generic PM/PMO → OPS.

---

## F. Edge Cases & Confidence Notes

1. **Legal Roles**: "Chuyên viên Pháp lý" can sit in OPS or as a separate legal vertical. Current: OPS. Future: Consider a "legal" vertical if ingest volume > 50 jobs/month.
2. **Quality Roles**: QA (Quality Assurance) in manufacturing operations = OPS. QA in software testing = TECH. Rule: Non-tech QA → OPS; Software/IT QA → TECH.
3. **Maintenance Technician**: Facilities maintenance (boiler, HVAC, plumbing) = OPS. System/network maintenance = TECH.
4. **Contract Manager**: Legal focus with negotiation = Legal/Compliance. Ops focus on execution/administration = OPS.
